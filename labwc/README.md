Switching to [labwc](https://github.com/labwc/labwc), no tabbing, not perfect, but works great for now.

Super = Win / Meta 键

## 1. 窗口与整体

| 快捷键               | 功能             |
| ------------------- | --------------- |
| `Super + Ctrl + Shift + Q` | 退出 labwc |
| `Super + W`         | 全屏切换           |
| `Super + A`         | 窗口置顶切换         |
| `Super + S`         | 跨 Workspace 显示 |
| `Super + Z`         | 最大化 / 恢复       |
| `Super + V`         | 最小化            |
| `Super + X`         | Rofi 启动器 |
| `Super + Shift + C` | 关闭窗口           |

## 2. 窗口定位

| 快捷键                 | 功能         |
| ------------------- | ---------- |
| `Super + D`         | 移至左上角      |
| `Super + E`         | 移至左下角      |
| `Super + F`         | 移至右上角      |
| `Super + T`         | 移至右下角      |
| `Super + Shift + D` | 吸附左上 1/4 屏 |
| `Super + Shift + E` | 吸附左下 1/4 屏 |
| `Super + Shift + F` | 吸附右上 1/4 屏 |
| `Super + Shift + T` | 吸附右下 1/4 屏 |

## 3. 窗口移动

| 快捷键         | 功能        |
| ----------- | --------- |
| `Super + N` | 向左移动 50px |
| `Super + I` | 向下移动 50px |
| `Super + O` | 向上移动 50px |
| `Super + U` | 向右移动 50px |

## 4. 窗口尺寸调整

| 快捷键                 | 功能      |
| ------------------- | ------- |
| `Super + Y`         | 左边缘向左扩展 |
| `Super + G`         | 下边缘向下扩展 |
| `Super + R`         | 上边缘向上扩展 |
| `Super + P`         | 右边缘向右扩展 |
| `Super + Shift + Y` | 左边缘向右收缩 |
| `Super + Shift + G` | 下边缘向上收缩 |
| `Super + Shift + R` | 上边缘向下收缩 |
| `Super + Shift + P` | 右边缘向左收缩 |

每次调整 40px。

## 5. 多显示器

| 快捷键                 | 功能        |
| ------------------- | --------- |
| `Super + H`         | 焦点移至左侧显示器 |
| `Super + J`         | 焦点移至下方显示器 |
| `Super + K`         | 焦点移至上方显示器 |
| `Super + L`         | 焦点移至右侧显示器 |
| `Super + Shift + H` | 窗口移至左侧显示器 |
| `Super + Shift + J` | 窗口移至下方显示器 |
| `Super + Shift + K` | 窗口移至上方显示器 |
| `Super + Shift + L` | 窗口移至右侧显示器 |

## 6. Workspace

| 快捷键                 | 功能                |
| ------------------- | ----------------- |
| `Super + 1`         | Workspace 1       |
| `Super + 2`         | Workspace 2       |
| `Super + 3`         | Workspace 3       |
| `Super + 4`         | Workspace 4       |
| `Super + Shift + 1` | 将窗口移至 Workspace 1 |
| `Super + Shift + 2` | 将窗口移至 Workspace 2 |
| `Super + Shift + 3` | 将窗口移至 Workspace 3 |
| `Super + Shift + 4` | 将窗口移至 Workspace 4 |

## 7. 系统

| 快捷键                        | 功能       |
| -------------------------- | -------- |
| `Super + Ctrl + B`         | 锁屏并关闭显示器 |
| `Super + Ctrl + Shift + B` | 系统挂起     |
| `Super + M`                | 通知中心开关   |
| `Super + Shift + M`        | 清除所有通知   |
